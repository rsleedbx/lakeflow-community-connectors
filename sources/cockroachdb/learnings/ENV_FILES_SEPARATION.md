# Environment Files - Separated by Concern

## Overview

Credentials are now separated into two files for better organization:

1. **`cockroachdb_cockroachcloud.env`** - CockroachDB database credentials
2. **`cockroachdb_cdc_azure.env`** - Azure Blob Storage credentials

Both files are located in: `sources/cockroachdb/.env/`

---

## File 1: CockroachDB Credentials

**Path**: `sources/cockroachdb/.env/cockroachdb_cockroachcloud.env`

**Purpose**: Database connection credentials for CockroachDB Serverless

**Format**:
```bash
# CockroachDB Serverless Connection
# Used by: cockroachdb.py connector and unit tests

# Full URL format (includes credentials)
export COCKROACHDB_URL="postgresql://user:password@host:26257/database?sslmode=require"

# GitHub-style token format (used by cockroachdb.py)
export COCKROACHDB_TOKEN="user:password"

# Base URL without credentials (used by cockroachdb.py)
export COCKROACHDB_BASE_URL="postgresql://host:26257/database?sslmode=require"
```

**Used by**:
- `cockroachdb.py` connector (all modes)
- Unit test notebook (`cockroachdb.ipynb`)
- CDC test scripts
- Pipeline creation scripts

---

## File 2: Azure Storage Credentials

**Path**: `sources/cockroachdb/.env/cockroachdb_cdc_azure.env`

**Purpose**: Azure Blob Storage credentials for CDC changefeeds

**Format**:
```bash
# Azure Blob Storage for CockroachDB Changefeed
# Used by: Azure Parquet mode, CDC pipelines

export AZURE_STORAGE_ACCOUNT=cockroachcdc1766424661
export AZURE_STORAGE_KEY=<your-key>
export AZURE_STORAGE_CONTAINER=changefeed-events
export AZURE_CONNECTION_STRING=<connection-string>
export CHANGEFEED_URI=azure-blob://changefeed-events?AZURE_ACCOUNT_NAME=...
```

**Generated by**: `setup_azure_blob_for_cdc.sh`

**Used by**:
- `cockroachdb.py` connector (Azure Parquet mode only)
- Unit test notebook (for Azure Parquet tests)
- Azure CDC test scripts
- Azure Parquet pipeline creation

---

## Setup Instructions

### 1. Create CockroachDB Credentials File

```bash
cat > sources/cockroachdb/.env/cockroachdb_cockroachcloud.env << 'EOF'
export COCKROACHDB_URL="postgresql://user:password@host:26257/database?sslmode=require"
export COCKROACHDB_TOKEN="user:password"
export COCKROACHDB_BASE_URL="postgresql://host:26257/database?sslmode=require"
EOF
```

Replace:
- `user:password` - Your CockroachDB username and password
- `host` - Your CockroachDB cluster hostname
- `database` - Your database name (e.g., `ycsb`)

### 2. Create Azure Storage

```bash
cd sources/cockroachdb/scripts
./setup_azure_blob_for_cdc.sh
```

This will create `cockroachdb_cdc_azure.env` automatically.

## Benefits

### 1. Separation of Concerns
- Database credentials separate from storage credentials
- Easier to update one without affecting the other

### 2. Security
- Different access levels (database vs. storage)
- Can share Azure credentials without database access
- Can grant database access without storage access

### 3. Reusability
- CockroachDB credentials work across all modes (Direct, Azure, Volume)
- Azure credentials only needed for Azure Parquet mode
- Same CockroachDB file can be used with different storage backends

### 4. Clarity
- Clear file names indicate what credentials are inside
- Easy to identify which file to update for each service

## Migration from Old Format

If you have an existing combined file:

```bash
# Old file (deprecated)
sources/cockroachdb/.env/cockroachdb_cdc_azure.env (with both Azure + CockroachDB)

# New files (current)
sources/cockroachdb/.env/cockroachdb_cockroachcloud.env  # CockroachDB only
sources/cockroachdb/.env/cockroachdb_cdc_azure.env       # Azure only
```

**Migration steps**:

1. Extract CockroachDB credentials from old file
2. Create `cockroachdb_cockroachcloud.env` with those credentials
3. Remove CockroachDB credentials from `cockroachdb_cdc_azure.env`
4. Or simply re-run `setup_azure_blob_for_cdc.sh`
